Session 1: first app online. 14 October 2026. Egor Gaydukov with Dr. Martin Bielik (InfAU). The course is not a coding course and not an ethics course: it is a space to experiment with AI coding agents, so that what you can try is no longer limited by your technical skill. Plan: about four sessions with the tools, one session discussing what it means for designers, then an open "AI lab" every week for help with your projects.

  • Chat vs. agent: the same prompt (a 3D map of buildings between the Bauhaus main building and Weimar station) fails in a browser chat but works with Claude Code in VS Code, because the agent can read, write and run files in a folder and check its own result in the browser.
  • Setup: make your own repository from the course template on GitHub ("Use this template", public), open the folder in VS Code, open the terminal and start Claude.
  • CLAUDE.md is the project's standing instructions; slash commands (/model, /effort, custom commands); plan mode (Shift+Tab) asks questions and shows a plan before it works.
  • Context: long chats get worse; start a new chat with the learnings of the old one; memory files.
  • Your edge: be specific about what you want, build the environment (files, references, data) the agent needs, and stay responsible for how things are done.
  • Homework: publish your walking map online with GitHub Pages and add something crazy of your own.
