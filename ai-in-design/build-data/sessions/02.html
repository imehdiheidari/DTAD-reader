Session 2: AI models and an urban block in Rhino. 21 October 2026. Egor Gaydukov.

  • Types of models (cheat sheet on the Miro board): text to text, vision, speech to text, text to voice, text to image, image analysis (depth, segmentation), image/text to video, image/text to 3D, video to 3D scenes (point clouds, Gaussian splats), world models.
  • Online through an API (paid, best quality) or locally on your laptop (free, needs 8 to 16 GB of video memory for a useful text model). Chain models together: speech to text, text model, text to speech, plus vision, and you have a talking object.
  • Marketplaces such as Replicate give one API key for many models (Nano Banana, FLUX Kontext, video, audio); an image costs a few cents.
  • Live demo: load the Weimar file into Rhino through the MCP server, draw a plot polyline on its own layer, ask Claude to build a parametric urban block in Grasshopper (script components, streets, trees, low-poly trees from a reference image, facade details), set up a named view.
  • API keys go in a .env file and the file name goes in .gitignore, so it is never pushed to GitHub or pasted into a chat.
  • Render the saved view with Nano Banana and FLUX through Replicate, then publish the result online.
  • Discussion: what value designers add when tools can do more and more of the work.
  • Homework: integrate AI "intelligence" into the app you built, in an interesting way (not just a chat box).
