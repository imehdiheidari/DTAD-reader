جلسه ۱ (۱۴ اکتبر): اولین اپ آنلاین

مدرس: Egor Gaydukov با کمک Dr. Martin Bielik (گروه InfAU). این درس نه کلاس برنامه‌نویسی است و نه کلاس اخلاق هوش مصنوعی. هدفش این است که با ایجنت‌های کدنویس هوش مصنوعی آزمایش کنید تا مهارت فنی دیگر محدودتان نکند. حدود چهار جلسه کار با ابزارها، یک جلسه بحث درباره‌ی اینکه این برای طراحان چه معنایی دارد، و بعد کلاس به «AI lab» تبدیل می‌شود: هر هفته مدرس‌ها آنجا هستند تا در پروژه‌هایتان (به‌خصوص استودیو DTAD) کمک کنند.

چت در مرورگر در برابر ایجنت: یک پرامپت یکسان («نقشه‌ی سه‌بعدی ساختمان‌های بین ساختمان اصلی باهاوس و ایستگاه قطار وایمار») در چت معمولی به بن‌بست می‌رسد و از تو می‌خواهد خودت داده را از OpenStreetMap بگیری. ولی Claude Code در VS Code به یک پوشه روی کامپیوترت دسترسی دارد: فایل می‌سازد، می‌خواند و ویرایش می‌کند، دستور اجرا می‌کند، اول سؤال می‌پرسد، نتیجه را در مرورگر با اسکرین‌شات چک می‌کند و خطاها را خودش درست می‌کند. حاصل در حدود هفت دقیقه یک اپ آنلاین بود.

غیرقطعی بودن: با پرامپت یکسان نتیجه‌ها شبیه‌اند ولی یکی نیستند، چون جواب بر اساس احتمال ساخته می‌شود. برای فرار از «محتمل‌ترین» نتیجه باید دقیق‌تر بگویی چه می‌خواهی (موضوع یکی از جلسه‌های بعد).

راه‌اندازی:

  • از ریپوی الگوی درس در GitHub با دکمه‌ی Use this template یک ریپوی عمومی (public) در حساب خودت بساز. ریپو یعنی پوشه‌ای از فایل‌ها؛ branch یعنی نسخه‌ی جداگانه برای امتحان کردن تغییر بدون خراب کردن نسخه‌ی اصلی.
  • پوشه را در VS Code باز کن (یا ریپو را به صورت ZIP دانلود کن). داخلش داده‌ی هندسی وایمار، پوشه‌ی src برای کد اپ، فایل packages و README هست.
  • فایل‌های .md (مارک‌داون) متن ساده با چند علامت برای تیتر و کد هستند و از این به بعد «بهترین دوستت» هستند.
  • در VS Code ترمینال را باز کن و claude را تایپ کن.

اشتراک: فقط پنج جای اشتراک ۲۰ دلاری از طرف دانشگاه هست و بقیه باید با آن پنج نفر شریک شوند. چون سقف توکن دارد، توصیه شد اگر زیاد کار می‌کنی اشتراک خودت را بگیری.

ابزارهای مهم در Claude Code:

  • CLAUDE.md: ایجنت مثل شخصیت فیلم «ممنتو» حافظه‌ی کوتاه دارد. این فایل در شروع هر چت خوانده می‌شود: نقشه‌ی پروژه و دستورهای ثابت (مثلاً «هیچ‌وقت خط تیره‌ی بلند استفاده نکن»).
  • دستورهای اسلش: /model برای انتخاب مدل، /effort برای میزان تلاش (پیش‌فرض medium)، /resume برای برگشتن به چت‌های قبلی، و دستورهای سفارشی خودت. با @ می‌توانی به فایل یا پوشه‌ی مشخص اشاره کنی.
  • Plan mode (با Shift+Tab): کار را به قدم‌های کوچک تقسیم می‌کند، سؤال می‌پرسد و قبل از شروع برنامه را نشانت می‌دهد تا تأیید یا اصلاحش کنی.
  • چند ترمینال هم‌زمان: هر ترمینال یک چت جداست و می‌توانند موازی کار کنند. انگار یک شرکت نرم‌افزاری به ارث برده‌ای و باید کار را تقسیم و مدیریت کنی؛ مهارتی که در همکاری واقعی هم به کار می‌آید.
  • اگر خطایی بود: Ctrl+Shift+I در مرورگر، بخش Console، خطا را کپی کن و به ایجنت بده. برای دیدن اپ روی کامپیوتر خودت: npm run dev و لینک localhost.

کانتکست و حافظه: هر چه چت طولانی‌تر شود، کیفیت پایین می‌آید (قاعده‌ی سرانگشتی: بیشتر از ۳۰٪ کانتکست مصرف نکن). بهتر است از مدل بخواهی آموخته‌های چت را جمع کند و با آنها یک چت تازه شروع کنی. لایه‌ها: system prompt شرکت، بعد CLAUDE.md که خودت تعریف می‌کنی، بعد خود گفتگو. «memory» هم فایلی است که ترجیحات و آموخته‌ها را نگه می‌دارد.

برتری تو در برابر مدل‌ها: (۱) دقیق بدانی چه می‌خواهی و چطور. (۲) محیط مناسب بسازی: مثلاً برای پایان‌نامه یک پوشه‌ی منابع و یک سند که خروجی مطلوب را دقیق تعریف کند. (۳) مسئولیت: بهترین نتیجه همان است که تخصص خودت پشتش باشد؛ هرجا تخصص نداری، فقط «محتمل‌ترین» خروجی را می‌گیری. لازم نیست اجرای کد را بلد باشی ولی باید اصول پشت آن را بفهمی و پایش بایستی.

تمرین کلاس: همه با یک پرامپت آماده اپی ساختند که نشان می‌دهد از هر نقطه‌ی وایمار تا کجا می‌شود پیاده رفت. مدرس در plan mode اضافه کرد که کدام مغازه‌ها (از OSM، خرده‌فروشی و خوراکی) در پنج دقیقه قابل دسترس‌اند، و بعد آن را با GitHub Pages منتشر کرد.
