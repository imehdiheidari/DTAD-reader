Session 4: running the competition machine. 4 November 2026. Egor Gaydukov. The room recording is hard to hear in places, so parts of this transcript are rough.

  • Results of the first week: 21 skills, several full runs of the Europan "competition machine", and the problems they showed. Most of the work was making the skills talk to each other, not making each skill good on its own.
  • Cost: models come in sizes (Haiku, Sonnet, Opus); the smartest is the most expensive. Give simple steps (apply a script to the site) a cheaper model and keep the smart one for jury, narrative and layout. Run fixed analyses (climate) once and reuse them, save scripts instead of regenerating, add an orchestrator agent. A full run went from about 30 to 21 dollars in API costs.
  • Lessons: find whether an error is inside a skill or in the joints between skills, and where it starts; build a "surface" to evaluate runs (a platform that visualizes each run; shared geometry files); hand drawings over as vectors; plan the panel layout and drawing scales early; carry the narrative into every step; hide some analysis from the narrative so it doesn't take over.
  • Group critique of the panels against the winning entries, collected as GitHub issues. Goal for next week: get as close to the winning panels as possible; everybody is responsible for the whole machine.
  • Discussion: what happens to the profession? Write a short text about it.
