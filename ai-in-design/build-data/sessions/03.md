# AI in Design · Session 3

> **Session 3: skills and a competition machine.** 28 October 2026. Egor Gaydukov.
> - Review of the homework (an urban block in Rhino/Grasshopper plus renders): it is fun and fast, but hard to steer to a specific idea. Work in small steps, describe the parts (columns, materials, apartment types) instead of a general style, sketch first, and restart from a written specification when errors pile up.
> - From prompt engineering to context engineering to harness engineering: design the environment the model works in.
> - Skills: short text files (plus optional scripts, templates, SVGs) that steer the model in one domain. Two kinds: domain knowledge the model lacks (for example isovist analysis), and your own experiential knowledge (how you or your office do things). Keep them short and read them yourself.
> - Where to get them: skills.sh, GitHub, /plugins in Claude Code (discover, installed, marketplaces). Install with npx skills add; global (all projects) or local (one folder). A plugin is a bundle of skills.
> - Demo: grill-me and Superpowers brainstorming ask you questions until your request is specific; a site plan (Schwarzplan) made with and without a skill, then "turn this session into a skill".
> - Next big task: a "competition machine" for a past Europan brief. Each student takes one skill (site, open space, drawings, visuals, jury, evaluation...) in a shared repo, pushes changes, and the machine is run every few days.
